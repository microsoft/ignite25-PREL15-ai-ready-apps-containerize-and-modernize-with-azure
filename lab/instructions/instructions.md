# Lab Instructions


## Abstract
AI-Ready Apps: Containerize and Modernize with Azure
Abstract: Modernize containerized apps with AI on Azure. Learn how to quickly deploy powerful, flexible AI-powered applications to Azure Container Apps. Gain hands-on experience using Azure OpenAI and open-source models on serverless GPUs for cost-efficient AI inferencing. Secure enterprise-grade apps and ensure compliance-all through a guided, real-world project.


## Lab Segments


### Segment 0: AI-Focused Introduction to Azure Container Apps (15m)
Get a GPU-first refresher on workload profiles, model packaging, hybrid orchestration, and observability patterns tailored for Azure Container Apps in just 15 minutes.
[View Segment Instructions](segment0-ai-gpu-playbook.md)


### Segment 1: AI Image Generation with Serverless GPUs on Azure Container Apps (45m)
Learn how to deploy and scale AI image generation models using serverless GPU capabilities on Azure Container Apps for cost-effective AI inferencing.
[View Segment Instructions](skillable_gpu_aca_lab.md) 


### Segment 2: Modernizing Enterprise Applications with Azure OpenAI Integration (45m)
Discover how to integrate Azure OpenAI services into existing containerized applications to add intelligent features while maintaining enterprise security and compliance.
[View Segment Instructions](skillable_langchain_aca_lab 1.md)


### Segment 3: Ollama (30m)
Deploy a GPU-backed container app to host Ollama, preload multiple open-source models, compare prompt quality, and invoke the Ollama REST API with CLI tools.
[View Segment Instructions](segment3-ollama.md)


### Segment 4: MCP Shell Session Pools (45m)
Create and operate Shell-type session pools with the MCP Server enabled; retrieve MCP endpoints and API keys, launch remote shells, and run JSON-RPC commands.
[View Segment Instructions](segment4-mcp-shell.md)


### Segment 5: Open Source Agent (≤60m)
Deploy the Goose open-source AI agent stack with Azure Developer CLI, connect it to your existing Ollama GPU service, and optionally enable GitHub and Email MCP extensions.
[View Segment Instructions](segment5-goose-agent.md)
